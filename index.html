Platform Design Principles

The design habits behind Rui's production AI and data systems. Full implementation evidence remains in the Engineering Log.

Fault Isolation by Default

Failures stop at the tenant or workflow-node boundary, preserving useful work and making recovery observable.

  • LangGraph recovery nodes diagnose a failed district without aborting the full run
  • Go ingestion isolates timeouts and authentication failures per school

Idempotent Operations

Deterministic stages and controlled reloads make partial failures safe to rerun without duplication or manual cleanup.

  • Batch scoring is reproducible from the same input snapshot
  • User-facing workflows include test modes before production writes or sends

Privacy by Architecture

Sensitive inference stays local and multi-tenant boundaries are structural, reducing reliance on downstream policy choices.

  • Local Ollama diagnostics keep student records off cloud LLM services
  • Tenant-scoped data paths and local audit logs support review
