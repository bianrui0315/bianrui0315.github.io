Free Image Tools

Rui built a free, open-source suite of 50+ focused image utilities. A problem-first finder routes everyday requests into private browser workflows for compression, conversion, resizing, PDF tasks, and more.

The Product Problem

Many online image utilities require users to upload files for simple transformations. Rui positioned Free Image Tools around a clearer promise: common image work should be fast, free, inspectable, and private by default.

Rui's Role

Rui built the problem-first product surface, browser processing flows, multilingual navigation, returning-user shortcuts, Cloudflare deployment, SEO-oriented tool pages, and collaboration-friendly open-source repository.

What Rui Built

  • Problem-first discovery: users can describe an image problem in normal language, choose a common fix, or browse 50+ focused utilities.
  • Browser-first processing: compression, resizing, format conversion, and batch workflows run locally with Web APIs.
  • Privacy-centered UX: no upload required for core tools, no server-side file storage, and metadata-removal workflows for safer sharing.
  • Production tool controls: output formats, target sizes, adjustable quality, EXIF removal, batch downloads, and mobile handoff are presented as task-specific controls rather than a generic editor.
  • Workflow continuity: My Tools, recently used shortcuts, saved tools, sharing, and multilingual navigation help repeat users return quickly.
  • Optional AI layer: AI alt-text generation supports accessibility and SEO without making the core product depend on account creation or paid tiers.

Open Collaboration

The website is free to use and the repository is public. Rui invites developers and users to report issues, suggest tools, open pull requests, and improve the project together.
